# 数据与隐私

## 默认保存在哪里

会话、精确经纬度、时间、精度及可选行政区保存在 Android 应用的本地数据库中。
应用设置另存于 DataStore。核心记录与导出不需要账号或 API key。

应用通过 Android 系统/Google Play services 的定位能力获取位置，其系统级网络行为
受设备与 Google Play services 设置影响。本说明描述 GPSLog 自身的网络操作。

## 两个可选网络功能

**行政区解析**默认关闭。开启后使用 Android Geocoder 解析位置，可能把位置交给设备配置的
地理编码服务；GPSLog 对查询进行缓存、限流和退避，但不控制该服务商的数据保留策略。

**轨迹上传**默认关闭，服务器地址默认为空。用户配置 HTTPS 地址和 token 后才可使用。
开启自动上传时，符合条件的已结束历史会话也可能进入上传队列，不仅限于之后的新会话。
上传内容包含导出的会话和位置点；手动重试是显式上传操作。
数据接收方、访问权限与保留期限由用户选择的服务器负责。仓库不提供公共上传服务。

上传 token 使用 Android Keystore 支持的加密方式保存，普通设置与凭据分开。
HTTP 客户端不跟随重定向，不把 token 交给重定向目标；失败信息不记录原始响应内容或 token。

## 备份、迁移与删除

- Android 云备份规则排除轨迹数据库、GPSLog 设置与凭据。
- Android 设备间迁移允许复制轨迹数据库和设置，但排除上传凭据。迁移后需重新配置 token。
- 删除本机会话不会自动删除已经导出的文件或上传到服务器的副本；这些副本需分别管理。
- 通过系统文件选择器导出的 JSON/GPX/CSV 位于用户选择的位置，之后如何同步由文件提供方决定。

## 照片与诊断资料

桌面预览报告、执行计划、日志、备份和已标记照片可能包含精确位置、拍摄时间、相机信息
与绝对路径。`inspect --at` 也会输出匹配坐标。分享这些文件前需要单独脱敏。

使用 `private/`、`tracks/`、`photos/`、`reports/` 等未跟踪目录保存真实资料。
本仓库的样例是合成数据，不应通过真实轨迹更新它们。签名密钥、凭据、数据库、日志和
私人截图不属于源码发布内容。
